# Астралион: Наследие звёзд

**Космическая MMORPG на Godot 4 для Android.**

Галактика на пороге пробуждения древней сети. Независимый пилот начинает с первого контракта
в пограничной колонии, развивает корабль и постепенно раскрывает наследие звёздных миров.

> Текущее состояние: репозиторий содержит систему планирования разработки.
> Игровой клиент, сервер и админка пока не реализованы. Готового APK нет.

## Новая сессия Codex, Claude Code или другого ИИ

1. Прочитать [AGENTS.md](AGENTS.md).
2. Прочитать [PROJECT_STATE](docs/development/PROJECT_STATE.md).
3. Открыть текущий этап и TASK-файл; ROADMAP нужен при выборе следующей задачи.
4. Читать только связанные исходники и нужные разделы источника через индекс.

Не перечитывать весь GAME.md при каждом старте.
Не считать наличие файлов, коммит или архитектурный контракт работающей механикой.
Каждая задача имеет критерии и проверки; параллельная работа — отдельные владельцы и ветки.

## Ближайшая цель

Сначала зафиксировать стек и контракты. Затем подтвердить два клиента в одной области,
серверное движение и сохранение позиции, добавить один NPC, бой, квест, награду и базовую админку.
Android-загрузчик ресурсов, Визуальная студия и профилирование развиваются с ранних этапов.

## Создание навыков для ИИ-агентов

В `.agents/skills/skill-creator/` установлен официальный **Skill Creator** из
[openai/skills](https://github.com/openai/skills/tree/49f948faa9258a0c61caceaf225e179651397431/skills/.system/skill-creator).
Исходная версия: `49f948faa9258a0c61caceaf225e179651397431`; файлы скопированы без изменений,
лицензия Apache-2.0 сохранена в `LICENSE.txt` внутри навыка.

Откройте этот репозиторий в Codex и начните новую сессию. Пример запроса:

> Используй $skill-creator: создай навык для ИИ-агента, который проверяет документацию проекта. Сохрани его в .agents/skills/.

Навык содержит инструкции, генератор структуры нового навыка, генератор
`agents/openai.yaml` и проверку `SKILL.md`. Формат `SKILL.md` можно использовать
в других агентах, поддерживающих Agent Skills; обнаружение навыков зависит от агента.

Для запуска Python-скриптов нужны Python 3 и PyYAML (`python -m pip install pyyaml`).
Проверить созданный навык:

```sh
python .agents/skills/skill-creator/scripts/quick_validate.py .agents/skills/имя-навыка
```
