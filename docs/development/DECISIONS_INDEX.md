## Как уточнять контекст

Открыть запись ID, перейти к диапазону строк закреплённого источника и прочитать весь нужный
раздел с ограничениями и тестами. Для сцены также открыть SCENARIO-CH01 и соответствующий
SCENE-xx-DETAIL: дословные реплики и ID узлов не копируются сюда и не переименовываются.
Для спорной ранней формулировки проверить последующие явные уточнения через RISKS.md.
Если main обновился, сначала сравнить commit и затронутые ID; старые выводы не переносить автоматически.
