# Передача между сессиями и агентами

Первый результат: [INITIAL-AUDIT](INITIAL-AUDIT.md).
Полная повторная вычитка: [FULL-REVIEW](FULL-REVIEW.md).

Для следующей сессии создать `YYYY-MM-DD-TASK-ID.md` с коротким отчётом:

- ID задачи, исполнитель, ветка, базовый и итоговый SHA.
- Цель и реально изменённые файлы; ссылка на коммит/diff.
- Каждая обязательная команда/сценарий, окружение, результат и место логов.
- Отдельно: исходники, сборка, наличие тестов, результат тестов, runtime.
- Ошибки, UNVERIFIED, остаточные проблемы и вопросы для RISKS.
- Какие строки TASK/этапа/ROADMAP/PROJECT_STATE обновлены.
- Следующий ID, обязательные зависимости и минимальный набор чтения.

Передавать ссылки и результаты, а не копию GAME.md или всего исходного кода.
Общие документы правит один интегратор; handoff исполнителя не конфликтует с чужой работой.
Коммит без тестового результата не служит доказательством работоспособности.
